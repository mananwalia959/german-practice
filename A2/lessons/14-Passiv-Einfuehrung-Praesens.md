# Lektion 14: Passiv — Einführung (Präsens)
## Passive Voice — Introduction (Present Tense)

**Niveau:** A2
**Lernziele:**
- Form the passive voice in present tense (werden + Partizip II)
- Convert active sentences to passive
- Understand when and why to use the passive

---

## 1. Einführung

> **Aktiv:** Der Bäcker backt das Brot.
> **Passiv:** Das Brot **wird** (vom Bäcker) **gebacken**.

In the active sentence, we focus on the baker. In the passive, we focus on the bread — what happens to it. The agent (baker) becomes optional.

---

## 2. Grammatik-Erklärung

### 2.1 Formation: werden + Partizip II

**werden** (conjugated, position 2) + **Partizip II** (at the end)

| Person | werden |
|--------|--------|
| ich | werde |
| du | wirst |
| er/sie/es | **wird** |
| wir | werden |
| ihr | werdet |
| sie/Sie | werden |

| Active | Passive |
|--------|---------|
| Man reinigt das Büro. | Das Büro **wird** gereinigt. |
| Er repariert das Auto. | Das Auto **wird** repariert. |
| Die Köchin kocht die Suppe. | Die Suppe **wird** gekocht. |

### 2.2 Active → Passive Conversion

| Step | Example |
|------|---------|
| **Active sentence** | Der Arzt untersucht den Patienten. |
| 1. Akkusativ object → new subject | den Patienten → **der Patient** |
| 2. Subject → von + Dativ (optional) | der Arzt → **vom Arzt** |
| 3. Verb → wird + Partizip II | untersucht → **wird untersucht** |
| **Passive sentence** | Der Patient **wird** (vom Arzt) **untersucht**. |

> **Merke!** The accusative object of the active sentence becomes the **nominative subject** of the passive sentence.

> **Achtung!** Not all active sentences can be passivized — verbs with dative objects (helfen, gefallen) generally cannot form normal passive.

### 2.3 The Agent: von + Dativ

The original subject (who does the action) can be expressed with **von + Dativ**:
- Das Haus **wird vom Architekten** gebaut.
- Das Buch **wird von vielen Studenten** gelesen.

The agent is often **omitted** when unknown or unimportant:
- Hier **wird** nicht geraucht. (No agent needed)
- Das Fenster **wird** jeden Tag geputzt.

### 2.4 Passive with Modal Verbs

Modal verb (position 2) + Partizip II + **werden** (at end):
- Das **muss** sofort gemacht **werden**.
- Der Brief **kann** heute noch geschickt **werden**.
- Das **darf** nicht vergessen **werden**.

### 2.5 Impersonal Passive

Used for activities without a specific object. **es** fills position 1 (or is dropped when something else is there):
- **Es wird** hier nicht geraucht. = No smoking here.
- Hier **wird** viel gearbeitet. (es dropped when adverb takes position 1)
- Auf der Party **wurde** viel getanzt. (Präteritum — preview)

### 2.6 When to Use Passive

Use passive when:
- The **action/result** matters more than who does it
- The **agent is unknown**: Das Auto wurde gestohlen.
- The **agent is obvious**: Das Gesetz wird eingehalten.
- In **formal/scientific writing**: Die Proben werden analysiert.

## 3. Beispiele

| Aktiv | Passiv |
|-------|--------|
| Der Koch kocht die Suppe. | Die Suppe wird (vom Koch) gekocht. |
| Man öffnet das Geschäft um 9 Uhr. | Das Geschäft wird um 9 Uhr geöffnet. |
| Die Schüler lesen das Buch. | Das Buch wird von den Schülern gelesen. |
| Man spricht hier Deutsch. | Hier wird Deutsch gesprochen. |
| Der Mechaniker repariert das Auto. | Das Auto wird (vom Mechaniker) repariert. |
| Man putzt das Fenster. | Das Fenster wird geputzt. |
| Der Arzt untersucht den Patienten. | Der Patient wird (vom Arzt) untersucht. |
| Man baut eine neue Brücke. | Eine neue Brücke wird gebaut. |
| Der Lehrer erklärt die Aufgabe. | Die Aufgabe wird (vom Lehrer) erklärt. |
| Man bezahlt die Rechnung. | Die Rechnung wird bezahlt. |
| Das muss sofort erledigt werden. | (passive with modal) |
| Hier wird nicht geraucht. | (impersonal passive) |
| Das Paket wird heute geliefert. | The package is being delivered today. |
| Das Licht wird ausgemacht. | The light is turned off. |
| Das Formular wird ausgefüllt. | The form is being filled out. |
| Die E-Mail wird geschickt. | The email is being sent. |
| Das Essen wird bestellt. | The food is being ordered. |
| Die Kinder werden abgeholt. | The children are being picked up. |
| Das kann nicht geändert werden. | That cannot be changed. |
| Das Haus wird renoviert. | The house is being renovated. |

---

## 6. Zusammenfassung

- **Passiv Präsens** = **wird/werden** + Partizip II
- Active Akkusativ-object → Passive subject (Nominativ)
- Agent (optional): **von + Dativ**
- Passive with modals: **modal + Partizip II + werden**
- Impersonal passive: **es/adverb + wird + Partizip II** (no subject)
- Use passive to focus on the action, not the doer
