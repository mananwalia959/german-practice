# Lektion 12: Indirekte Rede — Konjunktiv I
## Indirect Speech — Subjunctive I

**Niveau:** B1
**Lernziele:**
- Form Konjunktiv I for all common verbs
- Use Konjunktiv I in indirect speech (newspaper/academic style)
- Know when to replace Konjunktiv I with Konjunktiv II

---

## 1. Einführung

> **Direct speech:** Der Minister sagte: „Ich bin zuversichtlich."
> **Indirect speech:** Der Minister sagte, er **sei** zuversichtlich.

Indirect speech reports what someone said without using their exact words. In formal/journalistic German, Konjunktiv I signals that the speaker is reporting, not personally confirming the statement.

---

## 2. Grammatik-Erklärung

### 2.1 Konjunktiv I — Formation

Take the **infinitive stem** + Konjunktiv I endings:

| Person | Ending | haben | sein | kommen |
|--------|--------|-------|------|--------|
| ich | -e | habe | **sei** | komme |
| du | -est | habest | sei(e)st | kommest |
| er/sie/es | **-e** | habe | **sei** | komme |
| wir | -en | haben | seien | kommen |
| ihr | -et | habet | seiet | kommet |
| sie/Sie | -en | haben | seien | kommen |

> **Merke!** The most useful form is **3rd person singular** (-e ending), which is usually distinct from the Indikativ.

**sein** is completely irregular — memorize: **er sei** (not "er ist")

### 2.2 More Konjunktiv I Forms

| Infinitive | KI (er/sie/es) | Indikativ |
|-----------|---------------|---------|
| sein | **sei** | ist |
| haben | **habe** | hat |
| werden | **werde** | wird |
| kommen | **komme** | kommt |
| gehen | **gehe** | geht |
| sagen | **sage** | sagt |
| können | **könne** | kann |
| müssen | **müsse** | muss |
| wollen | **wolle** | will |
| sollen | **solle** | soll |
| dürfen | **dürfe** | darf |
| wissen | **wisse** | weiß |
| machen | **mache** | macht |
| fahren | **fahre** | fährt |

### 2.3 When KI = Indikativ → Use KII Instead

The whole point of KI is to be **distinct** from the Indikativ. When KI and Indikativ look the same, use **Konjunktiv II** to maintain the reported-speech signal:

| Person | Indikativ | KI | Problem? | Solution |
|--------|----------|----|----|---------|
| er komme | kommt | komme | ✓ distinct | use KI |
| sie kommen | kommen | kommen | ✗ identical | use **kämen** (KII) |
| wir haben | haben | haben | ✗ identical | use **hätten** (KII) |

**Rule:** 3rd person singular is usually safe for KI. For other persons, often use KII.

### 2.4 Tenses in Indirect Speech (Konjunktiv I)

| Direct speech tense | Indirect speech (KI) |
|--------------------|---------------------|
| Präsens (ist) | KI Präsens: **sei** |
| Perfekt (hat gesagt) | KI Perfekt: **habe gesagt** |
| Futur (wird kommen) | KI Futur: **werde kommen** |

**KI Perfekt:** habe/sei + Partizip II
- „Ich habe das gemacht." → Er sagte, er **habe** das gemacht.
- „Er ist gekommen." → Sie berichtete, er **sei** gekommen.

### 2.5 Direct → Indirect Speech: Full Process

**Steps:**
1. Remove quotation marks
2. Change verb to KI (or KII if KI = Indikativ)
3. Adjust pronouns and possessives
4. Use comma + dass OR just comma (dass is optional)

| Direct | Indirect |
|--------|---------|
| Er sagte: „Ich bin krank." | Er sagte, er **sei** krank. |
| Er sagte: „Mein Auto ist kaputt." | Er sagte, sein Auto **sei** kaputt. |
| Sie erklärte: „Ich habe das nicht gewusst." | Sie erklärte, sie **habe** das nicht gewusst. |
| Er behauptete: „Wir kommen morgen." | Er behauptete, sie **kämen** morgen. (KII — they/wir forms) |

**Pronoun shifts:**
- "ich" → er/sie
- "mein" → sein/ihr
- "wir" → sie
- "unser" → ihr

### 2.6 Reporting Verbs

| Verb | Meaning |
|------|---------|
| sagen | to say |
| behaupten | to claim |
| erklären | to explain |
| berichten | to report |
| meinen | to believe/think |
| mitteilen | to inform |
| betonen | to emphasize |
| versichern | to assure |
| zugeben | to admit |
| bestreiten | to deny |

## 3. Beispiele

| Direkte Rede | Indirekte Rede (KI) |
|-------------|-------------------|
| Er sagte: „Ich bin müde." | Er sagte, er sei müde. |
| Sie sagte: „Das stimmt nicht." | Sie sagte, das stimme nicht. |
| Er erklärte: „Ich habe keine Zeit." | Er erklärte, er habe keine Zeit. |
| Die Sprecherin sagte: „Die Preise steigen." | Die Sprecherin sagte, die Preise stiegen. (KII — steigen=KI identical) |
| Er behauptete: „Ich kenne ihn nicht." | Er behauptete, er kenne ihn nicht. |
| Sie versicherte: „Wir kommen pünktlich." | Sie versicherte, sie kämen pünktlich. (KII) |
| Er sagte: „Ich habe das Buch gelesen." | Er sagte, er habe das Buch gelesen. |
| Sie berichtete: „Er ist gestern angekommen." | Sie berichtete, er sei gestern angekommen. |
| Er meinte: „Das Wetter wird besser." | Er meinte, das Wetter werde besser. |
| Der Arzt erklärte: „Sie müssen sich ausruhen." | Der Arzt erklärte, sie müssten sich ausruhen. (KII) |
| Sie betonte: „Das ist sehr wichtig." | Sie betonte, das sei sehr wichtig. |
| Er gab zu: „Ich habe einen Fehler gemacht." | Er gab zu, er habe einen Fehler gemacht. |
| Die Politikerin sagte: „Wir werden die Steuern senken." | Die Politikerin sagte, sie würden die Steuern senken. (KII) |
| Er teilte mit: „Das Treffen ist abgesagt." | Er teilte mit, das Treffen sei abgesagt. |

## 6. Zusammenfassung

- **Konjunktiv I** = indirect speech marker in formal/journalistic German
- Formation: infinitive stem + -e/-est/-e/-en/-et/-en
- **sein** is irregular: **sei**, seien
- Most reliable form: **3rd person singular** (usually distinct from Indikativ)
- When KI = Indikativ → use **Konjunktiv II** instead
- KI Perfekt: **habe/sei** + Partizip II
- Pronoun/possessive shifts required when converting direct → indirect speech
