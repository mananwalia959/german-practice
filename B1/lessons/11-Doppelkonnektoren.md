# Lektion 11: Doppelkonnektoren
## Double/Paired Connectors

**Niveau:** B1
**Lernziele:**
- Learn all major paired connectors in German
- Understand word order rules for each pair
- Use double connectors to express complex logical relationships

---

## 1. Einführung

> Er spricht **sowohl** Deutsch **als auch** Englisch.
> **Nicht nur** ist er intelligent, **sondern** er ist **auch** sehr kreativ.
> **Je** mehr sie übt, **desto** besser wird ihr Deutsch.

Double connectors link two parallel elements or clauses and express relationships more precisely than simple conjunctions.

---

## 2. Grammatik-Erklärung

### 2.1 sowohl...als auch — both...and

Connects two parallel elements (can be nouns, verbs, adjectives, clauses).
- **Sowohl** Peter **als auch** Maria kommt. → verb: singular if one, plural if both "genuinely plural"
- Er spricht **sowohl** Deutsch **als auch** Französisch.
- Das ist **sowohl** interessant **als auch** nützlich.

> **Word order:** normal within each element; verb agrees with subject (often plural when two subjects)

### 2.2 nicht nur...sondern auch — not only...but also

Adds information that goes beyond the first element.
- Er ist **nicht nur** intelligent, **sondern** er ist **auch** fleißig.
- **Nicht nur** das Essen, **sondern auch** die Atmosphäre hat uns gefallen.
- Sie hat **nicht nur** eine Prüfung, **sondern auch** ein Referat.

> **Word order:** normal in each clause; **sondern** starts a main clause (verb second)

### 2.3 entweder...oder — either...or

Presents two alternatives.
- Du kannst **entweder** mit dem Bus **oder** mit der U-Bahn fahren.
- **Entweder** kommst du mit, **oder** ich gehe allein.

> **Word order:** When **entweder** starts a main clause → **verb-second inversion** in that clause: **Entweder** komme ich mit, **oder** du gehst allein.
> When entweder is in the middle → normal position: Du kannst **entweder** ... oder ...

### 2.4 weder...noch — neither...nor

Negates both elements (double negation = nothing at all).
- Er hat **weder** angerufen **noch** geschrieben.
- **Weder** Tee **noch** Kaffee trinke ich gern.
- Sie ist **weder** krank **noch** müde.

> **Word order:** each element has its normal position. When **weder** starts a clause → inversion.

### 2.5 je...desto/umso — the more...the more

Expresses proportional correlation. **Two comparative forms** are required.

**Structure:**
- **je** + comparative + subject + rest + **verb** (verb-final! subordinate-like)
- **desto/umso** + comparative + **verb** + subject (main clause, verb-second!)

| je-clause | desto/umso-clause |
|-----------|------------------|
| Je mehr ich lerne, | desto besser verstehe ich. |
| Je früher du anfängst, | umso mehr Zeit hast du. |
| Je teurer das Produkt ist, | desto besser ist die Qualität. |
| Je weniger er schläft, | desto müder wird er. |

> **Merke!** je-clause = verb at END (like subordinate clause); desto/umso-clause = verb SECOND (main clause inversion)

### 2.6 zwar...aber — it's true that...but / indeed...however

Concedes a point then contrasts it.
- Er ist **zwar** intelligent, **aber** er ist faul.
- Das stimmt **zwar**, **aber** das ändert nichts.
- **Zwar** hat er Recht, **aber** ich bin anderer Meinung.

> **Word order:** zwar goes in the middle of the clause or at start (→ inversion); aber starts a new main clause normally.

### 2.7 Summary Table

| Connector | Meaning | Word order note |
|-----------|---------|----------------|
| sowohl...als auch | both...and | normal; subject-verb agreement |
| nicht nur...sondern auch | not only...but also | normal |
| entweder...oder | either...or | entweder at start → inversion |
| weder...noch | neither...nor | both negated |
| je...desto/umso | the more...the more | je = verb-final; desto = verb-second |
| zwar...aber | it's true...but | zwar mid-field; aber = new clause |

## 3. Beispiele

| Deutsch | English |
|---------|---------|
| Sowohl mein Bruder als auch meine Schwester studiert Medizin. | Both my brother and my sister study medicine. |
| Er ist sowohl Arzt als auch Forscher. | He is both a doctor and a researcher. |
| Sowohl das Essen als auch der Service war ausgezeichnet. | Both the food and the service were excellent. |
| Sie spricht nicht nur Englisch, sondern auch Japanisch. | She doesn't only speak English but also Japanese. |
| Nicht nur hat er das Examen bestanden, sondern er hat auch Auszeichnung bekommen. | Not only did he pass the exam, but he also received a distinction. |
| Entweder du kommst mit, oder ich gehe ohne dich. | Either you come along, or I'll go without you. |
| Du kannst entweder Tee oder Kaffee haben. | You can have either tea or coffee. |
| Er hat weder angerufen noch eine SMS geschickt. | He neither called nor sent a text message. |
| Weder das Essen noch das Wetter hat uns gefallen. | Neither the food nor the weather pleased us. |
| Je mehr du lernst, desto besser wird dein Deutsch. | The more you learn, the better your German gets. |
| Je länger wir warten, umso schwieriger wird es. | The longer we wait, the more difficult it becomes. |
| Je weniger Schlaf er bekommt, desto schlechter konzentriert er sich. | The less sleep he gets, the worse he concentrates. |
| Er ist zwar nett, aber etwas seltsam. | He's nice, but a bit strange. |
| Das stimmt zwar, aber ich sehe das anders. | That may be true, but I see it differently. |
| Zwar kostet das viel Geld, aber es lohnt sich. | It's true that it costs a lot, but it's worth it. |
| Sowohl meine Mutter als auch mein Vater kommen zum Fest. | Both my mother and my father are coming to the party. |
| Nicht nur das, sondern auch das Gegenteil ist richtig. | Not only that, but the opposite is also correct. |
| Entweder lernst du, oder du fällst durch. | Either you study, or you fail. |
| Weder er noch sie weiß die Antwort. | Neither he nor she knows the answer. |
| Je günstiger das Ticket, desto früher muss man buchen. | The cheaper the ticket, the earlier you have to book. |

## 4. Übungen

### Übung 1: Lücken füllen

Wählen Sie den richtigen Konnektor.

1. Er ist ________ gut im Sport ________ in der Schule. (sowohl...als auch / weder...noch)
2. ________ kommt sie mit, ________ wir gehen ohne sie. (entweder...oder / je...desto)
3. ________ mehr ich esse, ________ hungriger werde ich. (je...desto / zwar...aber)
4. Das ist ________ teuer, ________ es ist sein Geld wert. (zwar...aber / nicht nur...sondern auch)
5. Sie hat ________ Geld ________ Zeit. (weder...noch / sowohl...als auch)

4. Je weniger man schläft, desto müder ist man.

## 6. Zusammenfassung

| Pair | Key rule |
|------|---------|
| sowohl...als auch | both elements positive |
| nicht nur...sondern auch | second element adds/emphasizes |
| entweder...oder | two alternatives |
| weder...noch | both negated |
| je...desto/umso | je = verb-final; desto = inverted |
| zwar...aber | concede then contrast |
