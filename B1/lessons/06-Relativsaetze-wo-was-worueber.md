# Lektion 06: Relativsätze mit wo, was und wo(r)-Verbindungen
## Relative Clauses with wo, was, and wo(r)- Compounds

**Niveau:** B1
**Lernziele:**
- Use **was** as a relative pronoun after alles, nichts, etwas, das, superlatives
- Use **wo** for places
- Form and use **wo(r)-** compounds (worüber, wofür, woran...)

---

## 1. Einführung

> **Alles, was** er sagt, stimmt. (Everything he says is true.)
> **Die Stadt, wo** ich aufgewachsen bin, heißt Wien. (The city where I grew up is called Vienna.)
> **Das Thema, worüber** wir gesprochen haben, war interessant. (The topic we talked about was interesting.)

These relative pronouns differ from the standard **der/die/das** pronouns learned in Lektion 05.

---

## 2. Grammatik-Erklärung

### 2.1 was — Relative Pronoun for Things/Concepts

**was** replaces **das** as a relative pronoun in these specific situations:

| Antecedent | Example |
|-----------|---------|
| **alles** | alles, **was** ich brauche (everything I need) |
| **nichts** | nichts, **was** mich interessiert (nothing that interests me) |
| **etwas** | etwas, **was** ich nicht verstehe (something I don't understand) |
| **das** (vague/demonstrative) | das, **was** du sagst (what you're saying) |
| **vieles** | vieles, **was** er erzählt hat |
| **einiges** | einiges, **was** mir gefällt |
| **manches** | manches, **was** schwierig ist |
| **weniges** | weniges, **was** ich weiß |
| **neuter superlative** | das Schönste, **was** ich je gesehen habe |
| **whole clause** | Er kam zu spät, **was** mich ärgerte. |

> **Merke!** After indefinite neuter pronouns and superlatives → use **was** not **das**.

> **Achtung!** Was has no case forms — it stays was in all positions (Nominativ, Akkusativ, etc.) **except** with prepositions (then use wo(r)- compound).

### 2.2 wo — Relative Pronoun for Places

**wo** replaces a **preposition + relative pronoun** (in dem, an dem, auf dem...) when the antecedent is a **place**:

| With preposition | With wo (more common) |
|-----------------|----------------------|
| Die Stadt, **in der** ich lebe, ... | Die Stadt, **wo** ich lebe, ... |
| Das Land, **aus dem** er kommt, ... | Das Land, **wo** er herkommt, ... |
| Der Ort, **an dem** wir uns treffen, ... | Der Ort, **wo** wir uns treffen, ... |

> **Tipp:** wo is especially natural in spoken German for place antecedents.

**wo** can also refer to time (somewhat literary):
- Der Tag, **wo** alles begann, war ein Dienstag. (= an dem)

### 2.3 wo(r)- Compounds

When the relative clause requires a **preposition + was**, combine them into a **wo(r)-** compound:

| Preposition | wo(r)- compound | Example |
|-----------|----------------|---------|
| über | **worüber** | das Thema, **worüber** wir sprachen |
| für | **wofür** | der Grund, **wofür** ich kämpfe |
| an | **woran** | das, **woran** ich denke |
| auf | **worauf** | die Sache, **worauf** ich warte |
| von | **wovon** | etwas, **wovon** ich träume |
| mit | **womit** | das Werkzeug, **womit** er arbeitet |
| zu | **wozu** | der Zweck, **wozu** das dient |
| vor | **wovor** | das, **wovor** ich Angst habe |
| aus | **woraus** | das Material, **woraus** es gemacht ist |
| in | **worin** | etwas, **worin** ich gut bin |
| um | **worum** | das, **worum** es geht |
| durch | **wodurch** | der Weg, **wodurch** das möglich wird |

> **Merke!** Rule: **wor-** (not wo-) before vowels: worüber, woran, worauf, woraus, worin — but: womit, wofür, wozu, wovon, wodurch (consonant → just wo-)

> **Wichtig!** wo(r)- compounds are used for **things/concepts only**. For **people**, use normal preposition + relative pronoun:
> - Das, **worüber** wir sprachen... (thing) ✓
> - Der Mann, **über den** wir sprachen... (person) ✓ (NOT: über wen)

### 2.4 Complete Overview

| Type | Use when | Example |
|------|---------|---------|
| **der/die/das/den/dem/deren...** | specific noun antecedent | der Mann, der ... |
| **was** | alles/nichts/etwas/das + superlatives + whole clause | alles, was ... |
| **wo** | place antecedent | die Stadt, wo ... |
| **wo(r)-** | thing/concept + preposition | das Thema, worüber ... |

## 3. Beispiele

| Deutsch | English |
|---------|---------|
| Alles, was er sagt, ist wahr. | Everything he says is true. |
| Nichts, was du machst, ist falsch. | Nothing you do is wrong. |
| Es gibt etwas, was ich dir sagen muss. | There's something I have to tell you. |
| Das, was du meinst, verstehe ich nicht. | What you mean, I don't understand. |
| Das war das Beste, was ich je gegessen habe. | That was the best thing I've ever eaten. |
| Das Schönste, was mir je passiert ist, war unsere Reise. | The most beautiful thing that ever happened to me was our trip. |
| Das war vieles, was wir besprechen mussten. | That was a lot that we had to discuss. |
| Er kam nicht, was mich überraschte. | He didn't come, which surprised me. |
| Die Stadt, wo ich aufgewachsen bin, heißt Graz. | The city where I grew up is called Graz. |
| Das ist das Café, wo wir uns kennengelernt haben. | That's the café where we met. |
| Das Dorf, wo meine Eltern wohnen, ist sehr klein. | The village where my parents live is very small. |
| Das Thema, worüber wir gesprochen haben, war Klimawandel. | The topic we talked about was climate change. |
| Die Arbeit, wofür er bezahlt wird, macht ihm Spaß. | The work he gets paid for is fun for him. |
| Das ist das, woran ich die ganze Zeit gedacht habe. | That's what I've been thinking about the whole time. |
| Etwas, worauf ich mich freue, ist der Urlaub. | Something I'm looking forward to is the holiday. |
| Ich weiß nicht, wovon du sprichst. | I don't know what you're talking about. |
| Das ist etwas, womit ich nicht einverstanden bin. | That's something I don't agree with. |
| Das Problem, wozu wir eine Lösung brauchen, ist komplex. | The problem we need a solution to is complex. |
| Das, wovor ich Angst habe, ist das Examen. | What I'm afraid of is the exam. |
| Das ist alles, woraus ich schließe, dass er kommt. | That's everything from which I conclude that he's coming. |

## 6. Zusammenfassung

- **was** = relative pronoun after alles, nichts, etwas, das, superlatives, and for whole-clause reference
- **wo** = relative pronoun for place antecedents (replaces in/an/auf + dem/der)
- **wo(r)-** compounds = preposition + was merged (worüber, wofür, woran, worauf, wovon, womit...)
- **wor-** before vowels, **wo-** before consonants
- wo(r)- for things; normal preposition + relative pronoun for people
