- Woerter auf **-ie** sind fast immer feminin: die Demokratie.
- Woerter auf **-er** (Personen, maennlich) sind maskulin: der Buerger, der Einwanderer.

## Zusammenfassung: Genus-Regeln

| Endung / Muster | Genus | Beispiele aus dieser Liste |
|-----------------|-------|---------------------------|
| -ung | feminin (immer) | die Regierung, die Bildung, die Verschmutzung, die Loesung |
| -keit / -igkeit | feminin (immer) | die Gerechtigkeit, die Arbeitslosigkeit, die Nachhaltigkeit |
| -heit | feminin (immer) | die Meinungsfreiheit, die Gleichberechtigung |
| -schaft | feminin (immer) | die Wirtschaft, die Wissenschaft, die Gesellschaft, die Gemeinschaft |
| -tion / -sion | feminin (immer) | die Inflation, die Koalition, die Emission, die Investition |
| -ie | feminin (fast immer) | die Demokratie, die Theorie, die Energie |
| -ur | feminin (fast immer) | die Kultur, die Literatur, die Skulptur |
| -e (abstrakt) | feminin (meistens) | die Folge, die Klage, die Ursache, die Massnahme |
| -ium | neutrum (immer) | das Ministerium, das Stipendium |
| -nis | neutrum (meistens) | das Ergebnis, das Gefaengnis, das Verbrechen |
| Ge- Praefix | neutrum (oft) | das Gericht, das Gesetz, das Gemaelde, das Gedicht |
| -er (Person) | maskulin (meistens) | der Forscher, der Richter, der Buerger, der Einwanderer |
| -ist | maskulin (immer) | der Komponist |
| -eur | maskulin (immer) | der Regisseur |
| Komposita | letztes Wort bestimmt | der Klima+wandel (der Wandel), die Solar+energie (die Energie) |
